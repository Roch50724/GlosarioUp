HTML y la Interfaz de Usuario

HTML (HyperText Markup Language) es el lenguaje de marcado estándar que se usa para estructurar el contenido de una página web: define títulos, párrafos, imágenes, botones y enlaces mediante etiquetas. Es la base sobre la que luego se aplican los estilos (CSS) y el comportamiento (JavaScript).

La Interfaz de Usuario (UI) es el conjunto de elementos visuales y de interacción — botones, menús, íconos, pantallas — mediante los cuales una persona se comunica con un sistema. En la práctica, el HTML construye el esqueleto de esa interfaz: cada botón o menú que ves en una página web nace de una etiqueta HTML.
